---
title: "My agent is not appearing on my website"
description: "Common reasons the agent does not show up and how to fix them."
---

Check these in order:

- **Organisation domain:** open Organisation settings and make sure your domain matches the site. The agent only loads on that domain and its subdomains, and nothing loads until a domain is set.
- **Embed code:** copy the code again from **Add to site** and check it sits before the closing `</body>` tag.
- **Rotated key:** if you rotated your key, old embed code stops working. Paste the new code.
- **Plan:** putting the agent live needs an active paid plan. If a payment failed and the grace period ended, the agent shows "This agent isn't available right now" until billing is fixed.
- **Caching:** clear your site's cache or any caching plugin, then reload.

If it still does not appear, [contact support](/troubleshooting/contacting-support).
