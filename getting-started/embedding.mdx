## One script tag is all it takes

Embedding Lark on your website is a single copy-paste. No plugin to install, no framework required — it works on any website that supports custom HTML.

## Getting your embed script

In your Lark dashboard, go to Organisation settings and open the **Embed** tab. You'll find a short script tag unique to your organisation:

```html
<script src="https://cdn.trylark.io/agent.js" data-org="your-org-id" defer></script>
```

## Where to place it

Paste the script just before the closing `</body>` tag on every page where you want the agent to appear.
